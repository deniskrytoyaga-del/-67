# 67 — Генератор тупых шуток

Веб-приложение и Android-сборка проекта для сайта 67.

- 300 случайных намеренно глупых шуток
- избранное хранится локально
- копирование шутки
- PWA / офлайн-кэш
- GitHub Actions собирает debug APK и прикрепляет его к релизу

Веб-версия: https://deniskrytoyaga-del.github.io/-67/jokes/
APK после успешной сборки: https://github.com/deniskrytoyaga-del/-67/releases/download/jokes-latest/app-debug.apk
